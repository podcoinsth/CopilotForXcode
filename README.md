## การเติมโค้ดให้สมบูรณ์

คุณสามารถรับคำแนะนำประเภทการเติมโค้ดอัตโนมัติจาก GitHub Copilot ได้ ไม่ว่าจะโดยการเริ่มต้นเขียนโค้ดที่ต้องการใช้ หรือโดยการเขียนคำอธิบายเป็นภาษาธรรมชาติเพื่ออธิบายสิ่งที่คุณต้องการให้โค้ดทำ.
